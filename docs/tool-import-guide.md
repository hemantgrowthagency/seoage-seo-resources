# Working with the examples

Open a CSV in a spreadsheet to see its column names. For tools with CSV input, paste the contents including the header and check the column mapping before analysing. For row-based planners, enter each example in the corresponding fields.

| Sample | Exercise | What to check |
|---|---|---|
| keyword-mapping | Assign one destination per search intent. | Someone looking for repair instructions should land on the guide. |
| internal-link | Inspect the two links between the guide and kits page. | The anchor should describe the destination when read on its own. |
| gsc-opportunity | Compare the two queries in the GSC Opportunity Analyzer. | The first query earned two clicks from 400 impressions. Check the search results before deciding to change the page. |
| redirect-map | Enter the old and new paths in the redirect planner. | Each old path points directly to a different relevant destination. Test the real HTTP responses separately before launch. |
| hreflang-planner | Enter the two regional URLs and their language codes. | Each page should reference itself and the other version. Verify reciprocal annotations on both pages. |
| ai-referral | Compare referral sessions and engagement by source. | Six of ten sessions from the first source were engaged. A referral alone cannot establish which answer cited a page. |
